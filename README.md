# Uykudaki Kedilerin Rüya Tercümanı

> Bu proje, ev kedilerinin REM uykusu sırasında ürettiği görüntüleri **resmî yazışma üslubuyla** Türkçeye çevirmek üzere kurulmuş, tamamen gereksiz fakat bilimsel iddialı bir girişimdir.

## Neden vardır?

Çünkü kediler rüya görür. Biz de onların rüyalarını noter tasdikli cümlelerle yazmak istedik. Başka bir gerekçe aranmasın.

## Kurulum

```bash
python3 ruya_tercumani.py
```

Python 3 yeter. Kedi zorunlu değildir ama tavsiye edilir.

## Kullanım

Program size bir rüya üretir ve bunu bakanlık genelgesi tadında tercüme eder.

Örnek çıktı:

```
Konu: Gece 03:14'te gerçekleşen kovalama faaliyetine ilişkin tutanak
Beyan: İlgili kedi, kırmızı lazer noktasının uluslararası hukukta tanınmadığını iddia etmektedir.
```

## Uyarı

Bu yazılım hiçbir kedinin rüyasını gerçekten okumaz. Sadece ciddi ciddi uydurur.
